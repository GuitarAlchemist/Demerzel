# Continuous improvement (Kaizen reflex)

> Moved out of `.claude/rules/continuous-improvement.md` (2026-07-19), where it was
> resident on every turn. It is judgment-shaped guidance for the *end* of a task,
> not a rule that needs to be in context while doing one.

Every interaction is a compounding opportunity. After completing any task, ask:

1. Did this reveal a gap in the GA chatbot, skills, or domain coverage?
   → **Create an issue.**
2. Did this teach us something reusable?
   → **Package it as a knowledge state** via `/seldon deliver`.
3. Did this validate or invalidate a governance artifact?
   → **Update the evolution-log citation.**
4. Could the development process itself be improved?
   → **Propose a Kaizen improvement.**
5. Do TARS, ix, or Demerzel need updating based on what we learned?
   → **Issue a directive** via the Galactic Protocol.

Never let an insight die — compound it.

Related: `/demerzel-compound`, `/demerzel-metafix`, `/learnings`, and the
ml-feedback loop.
