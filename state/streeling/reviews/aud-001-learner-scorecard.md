# AUD-001 learner scorecard — facilitator copy

Keep this away from the learner until the answer-free task is complete. Preserve the original response before discussing answers. This blank form is preparation, not a completed test.

| Task | Pass condition | Record as a misunderstanding if... |
|---|---|---|
| 1. Causal order | `C` sees raw `x` in A and filtered `E(x)` in B; EQ after C cannot retroactively change C's gain decision. | The learner claims the same detector input in both chains or a later EQ changes earlier gain reduction. |
| 2. Exact calculation | `A=[0,0.75,0.75,0]`, `B=[0,1,1,0]`, and `B[1]−A[1]=0.25`; this proves only noncommutativity for the declared synthetic operators. | Arithmetic differs, or the learner presents a listening, real compressor, or guitar-WAV conclusion. |
| 3. Fixture alignment | The recorded interval is mainly before its approximate first attack, unlike the render interval; two different source WAVs cannot isolate processing order. | The learner compares equal file times as equal event times or treats source differences as an order effect. |
| 4. Reproducible A/B | One source hash and sample rate; same pinned EQ coefficients and compressor revision/settings; independent state reset; explicit boundary/latency and onset alignment; raw plus logged level-matched outputs; gain-reduction trace and clipping check. | A different source or per-arm settings are accepted without a separate question, or no trace/alignment is requested. |
| 5. Interpret a weak report | `0.2 dB` with missing settings and alignment cannot choose an order; a neutral EQ or never-crossed threshold can yield a null; an apparent difference that vanishes after alignment/reset/level correction is rejected as an artifact. | A preferred order is declared from the number alone or a null is treated as proof that order never matters. |
