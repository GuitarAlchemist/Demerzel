# Lessons from the CS-004 agentic dogfood exercise

These lessons come from local observations on 2026-10-04. They are process candidates, not new policy. Keep the observation, change, and falsifier together so the next course or implementation cycle can test each one.

| Observation | Evidence | Small change to try | Falsifier / revisit trigger |
|---|---|---|---|
| A wmux agent appeared to run and its provider exited 0, yet declared sibling files were denied and no receipt existed. | [`wmux-dogfood-observation.md`](wmux-dogfood-observation.md) records the denied reads/write and missing marker. | At launch, declare exact read and receipt-write paths; count the lane as productive only after the target tool calls and final marker are observed. The bounded helper now passes session-scoped `--allowedTools` rules. | If exact rules are still denied, stop the lane and surface that denial; do not widen access, copy source, or count activity as progress. |
| A user-authorized retry read four files and wrote one marker-verified review without disturbing the existing Wayfinder lane. | [`review-followup-20261004.md`](review-followup-20261004.md) records the read/write calls, marker, and exact-pane cleanup. | Use one artifact and one completion marker for an independently reviewable handoff; preserve the prior session. | If the receipt is absent, malformed, or unsupported by tool activity, mark the attempt incomplete regardless of agent prose or exit code. |
| Candidate = baseline gave equal errors, but equality alone cannot reveal a comparator that always reports equal. | [`control-evidence.json`](control-evidence.json) and [`positive-control-evidence.json`](positive-control-evidence.json). | Pair the negative control with a known gain change and a known spectral filter change before interpreting candidate comparisons. | If those changes do not move their expected measures, repair the comparator before running ComfyUI experiments. |
| Half amplitude reduced reference RMS error while a second-harmonic filter changed centroid and worsened RMS. | [`positive-control-evidence.json`](positive-control-evidence.json). | Treat metrics as diagnostic; set the listener protocol before a candidate run and keep both improvements and regressions. | If a simpler manual A/B gives the same decisions with less setup, remove agent or ComfyUI ceremony from this step. |

The next practical dogfood trial should use the actual voicing or audio interface with a guitarist, capture setup time and failed steps, and compare the agent-assisted path with a small manual baseline. Current evidence comes from source inspection, fixture WAVs, mock bridge tests, and a bounded agent review. There is still no live ComfyUI refinement, browser AudioWorklet capture, or blinded listening verdict. Future agents should consume these receipts as data; they should not turn them into general design rules until repeated trials support them.

The [recursive-improvement log](recursive-improvement-evidence.json) gives the next cycle a minimal state: fixed input, observed failure, one harness or evaluation change, replay result, and missing measures. Run independent artifact work in parallel with one writer per artifact, then move receipts through an automated check and an independent review queue. Track ready-to-reviewed time, review waiting time, failed receipts, learner success, and post-review defects. A larger draft pile is a bottleneck signal, not exponential progress. If review waiting or defect rate grows with concurrency, cap work in progress or simplify the workflow before adding more agents.
